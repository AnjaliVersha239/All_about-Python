# All_about-Python
This repository contain a beginner_friendly Python programes.
They cover fundamental concepts such as variables, Loops, Conditional, Function and simple data structure.

# What_you_will_learn
- Accepting user input with `input()`
- Converting input to integers using `int()`
- Using `if`, `elif`, and `else` for decision-making and branching logics.
- Formatting output with `f-strings`
- Some basic question based on Logical and Conditional operators.
